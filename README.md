# Нейроофис 2.0 — сопровождение молодого предпринимателя от идеи до устойчивого бизнеса

Решение команды «Макрочелы» для кейс-чемпионата **«Альфа-Будущее 2026»** (направление: Платежный бизнес Альфа-Банка). Топ-50 команд чемпионата.

## О проекте

Кейс: разработать стратегию привлечения и удержания молодых предпринимателей 17-25 лет для Платежного бизнеса Альфа-Банка (эквайринг, Альфа-Касса, AlfaPOS, СБП и другие продукты). Средний возраст клиента направления сегодня - 42 года, молодая аудитория охвачена слабо, а ключевая метрика удержания в этом сегменте - не переток в другой банк, а выживание бизнеса.

## Ключевая идея

**Нейроофис 2.0** - самостоятельная виртуальная AI-команда предпринимателя (Референт, Бухгалтер, Юрист, Аналитик платежей, Советник, Маркетолог), которая сама собирает сигналы из банковских и рыночных данных, приоритизирует проблемы и возвращает предпринимателю единый план действий, требующий только подтверждения.

В основе технической реализации - **Alfa MCP**: единый AI-сервер, который подключает продукты Платёжного бизнеса (РКО, СБП, эквайринг, Альфа-Касса, AlfaPOS) к Нейроофису и заранее выявляет финансовые риски бизнеса, а не сообщает о них постфактум.

North Star Metric - **ARSB (Active Retained Supported Businesses)**: число молодых предпринимателей, подключенных к платёжному контуру Альфы, совершивших первый платёж и остающихся активными при сопровождении офиса.

## Структура решения

1. Исследование ЦА (17-25 лет): карта эмпатии, инсайты, источники (ФНС, ВЦИОМ, НАФИ, GUESSS, СберАналитика, Корпорация МСП) плюс 8 глубинных интервью
2. Приоритизация отраслей по RICE: Beauty, онлайн-образование, HoReCa
3. Анализ конкурентов: банки РФ, иностранный финтех (Stripe, Square, Revolut, Mercury), AI-сервисы, небанковские инструменты (YCLIENTS, Tilda), смежные сферы (Duolingo, Nike, Gymshark)
4. Продуктовая стратегия: Нейроофис 2.0 и Alfa MCP
5. Стратегия продвижения: комьюнити, игра-симулятор «Мини Офис», шоу «Альфа-Карта Сокровищ»
6. Бизнес-модель и юнит-экономика: LTV/CAC = 3.66, payback period 7 месяцев, выход на операционную прибыль к 20-му месяцу
7. Roadmap на 24 месяца
